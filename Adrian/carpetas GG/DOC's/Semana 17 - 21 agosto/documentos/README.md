# Documentos de Investigación

Esta carpeta está reservada para que coloques tus documentos de investigación de Word (como los temas de renderizado condicional, manejo de errores, localStorage, etc.).

> [!NOTE]
> **Instrucciones para Restaurar el archivo original:**
> El archivo `Renderizado Condicional en JSX.docx` que estaba en la carpeta original `Words` se eliminó temporalmente durante la creación inicial del proyecto React por parte del generador automático de Vite (que limpia el directorio para evitar conflictos).
> 
> Como tu carpeta está sincronizada con **OneDrive**, puedes restaurar el archivo en 2 clics:
> 1. Abre tu navegador e ingresa a tu cuenta de OneDrive en la web (o abre la aplicación de OneDrive en tu computadora).
> 2. Ve a la **Papelera de reciclaje** (Recycle Bin).
> 3. Selecciona el archivo `Renderizado Condicional en JSX.docx` y haz clic en **Restaurar** (Restore).
> 4. Una vez restaurado, muévelo a esta carpeta `documentos/` para mantener todo organizado.
